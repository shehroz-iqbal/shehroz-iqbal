Data analyst based in Pakistan. I build pipelines that bring administrative and statistical

for people who don't work with data every day.

**Featured project**

[**Pakistan district data: Census 2023**](https://github.com/shehroz-iqbal/pakistan-district-data) ·
[live dashboard](https://shehroz-iqbal.github.io/pakistan-district-data/)

Pakistan's 2023 census for all 136 districts. It does four things:

- cleans and joins ten census tables in DuckDB SQL
- reconciles the results with PBS's published totals (44 automated checks)
- rebuilds 2023 district boundaries from tehsil polygons
- publishes the data as CSV, Excel, GeoJSON and an interactive map

**Tools**

SQL (PostgreSQL, MySQL, DuckDB, BigQuery) · Python · n8n · Grafana · Looker Studio · Git
